# Quake MDL import/export plugin for Blender
![image embed](wiki/images/plugin_01_small.jpg)

### About:
Mdl exporter/importer for Blender 2.8+ (and 2.7x). Originally developed by taniwha for QuakeForge, updated for Blender 2.8 by khreathor with a little help of queenjaz.

This repository is a fork of [khreathor/mdl-for-blender](https://github.com/khreathor/mdl-for-blender). All credit for the plugin goes to the original authors listed below.

### Credits:
- **taniwha**: original author of the MDL import/export plugin, written for [QuakeForge](https://github.com/quakeforge/quakeforge)
- **[khreathor](https://github.com/khreathor)**: Blender 2.8+ port and long-term maintenance, including the Blender 4.x and 5 updates
- **queenjaz**: helped with the Blender 2.8 port
- **[lavender.pet](https://github.com/lavenderdotpet)**: ported the wiki from Bitbucket and added the example model
